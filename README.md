# MathRift

Monorepo for a 1v1 speed-math game (calculus-friendly) plus portfolio web and API.

- apps/web: Vite portfolio + practice demo
- apps/api: Next.js API for matches/scoring
- apps/mobile: Expo app (later)
- packages/math-engine: deterministic question generator + verification
- infra/supabase: SQL, policies, seeds
